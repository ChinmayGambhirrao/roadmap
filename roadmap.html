SDE1/SDE2 Product Company Roadmap

Target: March 2028 · ~4 YOE by then · Realistic level: SDE2

Target Companies

Primary: Razorpay, Swiggy, Zomato, Flipkart, Meesho, CRED, Postman, Freshworks, Zerodha, Zepto, PhonePe, BrowserStack, Groww

Stretch: Google, Amazon, Microsoft (India offices)

Phased Roadmap

Phase 1 – Foundations (Now – Month 6, ~Dec 2026)
  • NeetCode 150 in JavaScript — Arrays/Hashing done, Two Pointers in progress on track
  • TypeScript path: TS Handbook (done) → TypeScript Exercises → React TS Cheatsheet → Total TypeScript (Matt Pocock)
  • Convert butler app to TypeScript incrementally, file by file
  • System Design: Alex Xu Vol 1, 1–2 chapters/week, redraw diagrams from memory (background reading, not deep focus yet)
  • Docker basics: Dockerfile, docker-compose (once TS conversion is underway)
Phase 2 – Depth + Project 1 (Month 7–12, ~mid 2027)
  • NeetCode: move past 150 into targeted medium/hard practice on weak patterns
  • Finish Alex Xu Vol 1 fully; design 3–4 systems from scratch on paper (URL shortener, rate limiter, chat app)
  • Deliverable: Project 1 — full-stack (React + TS frontend, Node/Express or NestJS backend, real DB, Dockerized, deployed)
  • Start posting on X — weekly recap format, builds visibility ahead of application phase
Phase 3 – Interview Readiness + Project 2 (Month 13–18, ~late 2027)
  • Machine coding practice — timed builds (60–90 min): parking lot, rate limiter, feed pagination
  • Deliverable: Project 2 — something with system-design depth (e.g., notification service, small event-driven architecture)
  • Mock interviews (Pramp, peers, or paid mock services)
  • Identify referral contacts at target companies (LinkedIn, college seniors)
Phase 4 – Active Applications (Month 19–24, through March 2028)
  • Apply broadly across primary target list + stretch companies
  • Company-specific behavioral prep (e.g., Amazon Leadership Principles) once interviews are scheduled
  • Negotiate from an SDE2 position given ~4 YOE by application time
Later (Post-2028) – Senior-level depth, learned on the job
  • AWS/cloud infra depth, Kubernetes, Terraform, Kafka, service mesh — deliberately deferred
  • DDIA — deeper reinforcement once fundamentals aren’t new anymore
  • These are senior/staff-level skills best learned on real production systems, not pre-studied without context
